\section*{Evaluation}
Evaluation of segmentation algorithms has long been done by comparing the cell-predictions to a ground truth, masks drawn by humans, usually professionals in the respective field --- DeepCell and the TissueNet-project crowd-sourced supervised training. The human-centered approach has many short-comings, evident is the human labour required for manual segmentation, further the reliability of these segmentations. Distinguishing between cell, nucleus, extra-cellular-matrix, and others, is often a heuristic task. Nonetheless the quality of human segmentation exceeded computer vision, and in many cases continues to, though we experience limitations promptly. Especially in dense tissues like the spleen, such compact organs complicate elementary staining techniques, resulting in sub-par membrane and ribosome stains required for unubiquitous segmentation. The tissue available, as seen in Figure \figref{fig:focus} is notably [bad]. As to not rely on a ambiguous ground-truth I included two additional methods of evaluation. The first is based on principal component analysis (PCA), using the input-image, on which the segmentation was performed, to calculate metrics which indicate a \emph{good} segmentation. The second reference free examination [simply] compares the cell-predictions to each other --- this of course does not tell which is the closest to a human-identifiable truth, but instead which algorithm provides a stable prediction of the cells.

The test were performed using unet4nuclei's (\inlineprogram{U4N}) evaluation scripts \cite{noauthor_carpenterlab2019_caicedo_cytometrya_2025}, and the \inlineprogram{DeepCell-Toolbox} (\inlineprogram{DT}) package\cite{noauthor_deepcell-toolbox_2023}. \inlineprogram{U4N} solely matches the masks, ground-truth and prediction, to one another and calculates the JI, it then identifies the precision and recall using a user set threshold, and finally calculates the F-score.\\
Conversly, \inlineprogram{DT} constructs a graph connecting each prediction-mask to all ground-truth masks, with the edge representing the JI. If the JI is 1 then this pair is classified as valid, All unmatched predictions are then classified as either as a merge, multiple edges of a single prediction-node have a non-zero JI --- two cells of the ground-truth are merged into a single predicted cell. Or a split, if multiple edges of a GT-cell have a non-zero JI --- the predictions split a single GT-cell.\\

\subsubsection*{CellSegmentationEvaluator}
The CellSegmentationEvaluator (CSE) \cite{chen_evaluation_2023} uses principle component analysis on 11 values that aim to abstract the image for segmentation and the prediction. The values can be categorised as follows
\begin{itemize}
    \item[1)] cells cover most areas (NC)
    \item[2)] cells cover mostly the foreground (FFC, 1-FBC, FCF)
    \item[3)] cells cover nuclei (FMCN)
    \item[4)] homogeneous protein composition (1/(ACFV+1), FPCF)
    \item[5)] homogeneous cell type composition (1/(ACVC+1), FPCC, AS) 
    \item[6)] homogeneous cell size (1/ln(SSD))
\end{itemize}
This includes the following assumptions: a) cell types should be roughly similar in composition across all channels, b) cell types can be approximated by cell clusters; c) the average CV(coefficient of variation) across all clusters for a given number of clusters is a proxy for similarity in composition within cell types; d) averaging the average CV across all clusters across different numbers of the cluster is also a proxy for similarity in composition within cell types. This implies the use of histochemistry with multi-plex pannels, the stainings here are constraint to dapi, 18s, alphaSMA/Vimentin and ATP1A1/E-Cadherin/CD45.\\% 
Cell types were defined using KMeans clustering performed on the mean cell intensities across all channels after applying z-score standardization for each channel

% An important consideration to note is that our metrics are based in large part on the assumption that tissue images used for evaluation contain different cell types that vary in their expression of different markers. If a tissue image is largely uniform, then our measures of segmented cell homogeneity will yield similar results regardless of the accuracy of cell segmentation masks. The greater the number of channels measured and the larger the differences between cell types, the more discriminating our metrics will be.

% The metrics also do not make any assumptions about allowable cell shapes. Measuring cell shape is an inherent problem for 2D tissue images where 3D cells are only seen in a thin layer in the z-axis. Cells belonging to the same cell type might be captured at different angles or heights and therefore display different shapes. Although our metrics of homogeneity at the cell level solve this issue indirectly (since cells from the same cell type but at different views should have similar channel compositions), segmentation methods that produce cells and nuclei with unexpected shapes are not directly penalized.

\subsubsection*{Cross-Evaluation}
Since the confidence in a given ground-truth may be scant, a comparison between the predictions, each acting as the ground-truth and performing a reference-based analysis, can give [context] to the consistency of predictions. Owing to the equal input one would expect a congruence between well performing segmentations.\\ % to the similarity between model-structure
Consecutively comparing the predictions using IoU-based metrics results in symmetrical outputs, as seen in \figref{fig:results}. The congruency can be observed in the dc-tb based cross-ebaluation. the dinocell, mesmer, proseg, stardist and xoa predictions perform well, are congruent among each other. with cpsam, dissect and segger we see that none perform well, indicating that they are, as we see in the gt-based analysis, not good at explaining the tissue. the U4N based values are too low to see any trend. the threshold of .65 is probably to high.
