\subsection*{\color{stardist}\textsc{StarDist}}
The deep Convolutional Neural Network StarDist maps a cell, or nuclei, not to a bounding box but to a star-convex polygon or polyhedron, depending on the dimensionality of the task \cite{schmidt_cell_2018} \cite{weigert_star-convex_2020} \cite{weigert_nuclei_2022}. By replacing background-classification as a binary task with that of a Euclidean distance to the nearest background-pixel --- those not part of an object ---  StarDist theoretically better identifies roundish shapes, like nuclei. The actual bounds of the prediction are computed by following the k radial-directions until a pixel with a differing identification is encountered. This computation is GPU-implemented, meaning it can be accessed on demand during training. The 3D implementation replaces the U-net backbone with a 3D variant of ResNet to predict radial distances and object probabilities. Additionally to the python API a plugin for FIJI and QuPath are also available.\\
StarDist takes a single-channel single-layer input image and returns a labelled bitmap.
