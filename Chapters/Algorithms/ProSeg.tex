\subsection*{\color{proseg}\textsc{ProSeg}}
A probabilistic approach to transcript assignment and cell segmentation. The past success of Cellular Pots Models adaptability to not only cell sorting but also migration and chemotaxis as well as it's Metropolis-like sampling procedure permit conversion to a fully-probabilistic Markov-Chain-Monte-Carlo inference model for cell-gene correlation, thus segmenting based on gene-profile. Instead of a complete detachment from morphology-imaging data, as it suggests so far, the initialization of the model includes nuclear-segmentations, the next stage includes accommodations for possible variations in gene-expression. Further the model assesses transcript-shifting, either by leakage or erroneous transcript-localization, though limited to a user set amount.
