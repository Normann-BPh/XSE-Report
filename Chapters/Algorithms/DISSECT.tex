-- We actually got a paper in early July: doi.org/10.1038/s43588-026-01020-x -- \\
DISSECT is a tool developed to combine cytological image segmentation with SRT guided fine-tuning, thus it is one of the few algorithms incorporating the SRT data provided by the Xenium platform. ... encode image to feature map ... denoisewith U-Net ... DCN for smth ... Refinement of image and transcript segmentation masks via gradient field. ... 
Input is the SRT table in csv or tsv format, a multichannel input image ... Output is a single, labled bitmap. the z-coords of the srt-table are ignored.
