\subsection*{\color{mesmer}\textsc{DeepCell-Mesmer}}
DeepCells deep-learning model Mesmer is trained on the extensive TissueNet dataset, with a diverse set of tissues allowing {generalization to the full diversity of tissue types} constraint to the imaging methods available. The architecture is a\textit{ ResNet50 backbone coupled with a Feature Pyramid Network with four prediction heads}. The input requires a nucleus channel and a membrane or cytoplasm channel which is normalized, passed through the ResNet50 with skip connections to the Feature Pyramid. From this [state] the centre and shape of the cell are inferred, by watershed calculations extended to full-sized cells. Since the requirements to run Mesmer include two channel inputs a 3D segmentation on Xenium data is only possible if one provides sequential images.
