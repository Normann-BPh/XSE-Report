\subsection*{\color{segger}\textsc{segger}}
The Graph Neural Network \textsc{segger} aims to prevent typical errors in cell-segmentation --- over- and under-segmenting, misassigning transcripts, or technical errors, like missing DAPI-stains --- by re-thinking the challenge as a transcript-to-cell link prediction task. Transcripts and cells are represented as nodes, where inter-transcript edges embody the spatial relation, and transcript-cell edges the assignment. This integration of transcript localization with staining data achieves, according to the authors, 3D-aware segmentation. \cite{heidari_segger_2025}\\
The node network, implemented in a graph neural network (GNN), undergoes iterative revisions of the aggregate information, i.e. updating under consideration of each neighbour, to refine the assignment. Extending the node-network by converting the input to tree-based tiles allows for accessible and computationally viable network size. Further, localizing the input, expedites the supervised-learning approach of \textsc{segger}. Thereafter, now possessing a latent transcript-cell-space, the model assigns transcripts to cells, and clusters those unassigned, potentially revealing fragments or partial cells.\\
\textsc{segger} prefers the entirety of the \textsc{Xenium}-output directory as input. The predicted cells are presented as encoded (\textsc{wkb}) polygons.\\
This report utilizes not the original implementation of \textsc{segger} \cite{heidari_elihei2segger_dev_2026} but an updated version \cite{noauthor_dpeerlabsegger_2026}.
